# Redaction ledger

This release is built as a new public implementation rather than a blind copy.

Excluded classes:

- personal identity, institutions, contacts, account handles, and hostnames
- absolute local paths, cloud-storage paths, credentials, tokens, and SSH data
- runtime logs, journals, task history, caches, and private service wrappers
- real projects, experiments, raw data, reports, images, and historical outputs
- upstream/private reference snapshots and unverified third-party material

Review status: initial staging complete; run the release checker before any
remote publication.
